# Friend Circle Manager

I want to develop a platform where i can keep the records of my friend circles. 1 friend might be in multiple friend circle. Friend should have a profile where their information like favorite color, food, interests etc should be store systematically. The system should have a function to maintain the birthdays upcoming and due and guide us what kind of gifts should we buy. We should be allowed to update their interests and information as days goes
